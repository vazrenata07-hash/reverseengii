# Preferências do usuário para este projeto

- Escrever o código e publicar no GitHub sem executar testes ou uma análise
  aprofundada posterior à escrita. Os testes nos dispositivos são feitos pelo
  usuário. Esta preferência foi informada em 23/10/2026.
- Compilar, empacotar e assinar são etapas da entrega solicitada.
- Não pedir novamente logs de crash como condição para implementar.
- Usar o mod fornecido como referência de comportamento; escrever código
  próprio em vez de reutilizar seu carregador.
- Informar com precisão o que foi implementado e o que ainda não foi confirmado
  em execução. Não apresentar protótipo como compatibilidade ou trial comprovados.
